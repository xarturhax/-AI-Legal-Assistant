## Уточнение запросов без обстоятельств

из оценки предмета запроса. Дополнительно учитывается явное название из словаря OSTIS.
Entities и facts предварительно проверяются на цитирование исходного текста.
Выдуманные обстоятельства и названия сущностей не дают разрешение на поиск.

содержит общий вопрос об обстоятельствах, а поиск не запускается. При известном
предмете needs_clarification и missing_information сохраняют частичный поиск.
