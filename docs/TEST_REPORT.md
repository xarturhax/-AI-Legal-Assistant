## Покрытые сценарии

Вход, регистрация, одноразовые коды, восстановление с отзывом сессий; доступ двух пользователей
к заметкам/профилю; гость 401; CSRF и автоэкранирование HTML; календарь и даты/часовые пояса;
миграции, foreign_keys=ON и сохранение данных при новом экземпляре приложения с тем же файлом.
Форум: создание темы/сообщения, чужие изменения запрещены, мягкое удаление, оценки уникальны,
буквальный поиск защищён от SQL-подобной строки. RSS offline-кеш проверен только mock transport.
Персональные рекомендации используют только свои просмотры/обратную связь; негативная оценка
одного пользователя не скрывает тему другому. Проверены тематические фильтры и поиск близких слов.
Заполнение документа проверено технической фикстурой; это не настоящий юридический бланк.

LLM-контракты: строгая JSON-схема, посторонние поля запрещены, неподтверждённый факт помечается
false; после двух ошибок JSON возвращается ошибка. Baseline не вызывает модель, а отсутствие OSTIS
блокирует LLM-ветку до генерации. Корреляция и параллельные операции проверены с явной mock-подменой
subprocess, не на живом sc-server. Реальных таймаутов модели и качества интерпретации не измерено.
